## 4. Post di lancio / Launch post

### English version

> **PyBlog – a complete blog engine in a single Python file**
>
> I wanted a blog that was fast, that I fully owned, with no WordPress and no database to maintain. So I built PyBlog: a single `pyblog.py` file, zero external dependencies, runs with just `python3`.
>
> You write articles with a WYSIWYG editor in the browser, hit save, and it generates lightweight static HTML that nginx serves in milliseconds. Python only runs the admin area and can stay off the rest of the time.
>
> What it does:
> - In-browser visual editor (Quill): images, code blocks, tables, videos
> - Bilingual sites with one-click AI translation (DeepL, Google, Claude, OpenAI, DeepSeek)
> - Full SEO: meta tags, JSON-LD, sitemap, robots.txt, RSS, even llms.txt for AI crawlers
> - Articles as plain JSON files — no database, no lock-in
> - Password-protected admin, dark mode, full-text search, comments (Giscus/Disqus)
>
> It's MIT licensed. I'd love your feedback.
>
> Repo: https://github.com/giuseppeciuni/pyblog

### Versione italiana

> **PyBlog – un motore di blog completo in un solo file Python**
